# Maison Élise — интернет-магазин одежды (Франция)

Бутик женской одежды «Maison Élise» (Париж) — полностью на французском языке. Демонстрирует умение строить клиентскую e-commerce логику на чистом JavaScript: каталог, фильтры, сортировку, выбор размера и корзину.

## Что внутри

- **Каталог из 12 товаров**, генерируемый из JS-массива данных (название, категория, цена в €, описание, бейджи)
- **Quick view**: клик по товару открывает полноценную карточку — большой визуал, описание, детали, выбор размера и количества
- **Корзина с сохранением в localStorage** — не сбрасывается при перезагрузке страницы
- **Вишлист**: сердечки на карточках, счётчик в шапке, состояние тоже хранится в localStorage
- **Fly-to-cart анимация**: при добавлении точка «летит» от кнопки в корзину, кнопка корзины «подпрыгивает»
- **Плавное увеличение фото при наведении** + оверлей «Aperçu rapide»
- **Фильтрация по категориям** и **сортировка по цене**
- **Модальное окно выбора размера** (XS–XL) — товар нельзя добавить без размера
- **Корзина-drawer**: изменение количества, пересчёт итога, прогресс до бесплатной доставки от 150 €
- Закрытие модалок по `Esc`, **тост-уведомления**, форма подписки с валидацией
- **Фотографии товаров**: 12 студийных каталожных фото, снятых в единой серии — одна модель, один кремовый фон, вещь видна целиком; кадрированы в 3:4 (720×960) и хранятся локально — сайт не зависит от внешних сервисов картинок, ленивая загрузка (`loading="lazy"`)
- Фото используются в каталоге, quick view и корзине; в герое — фото в рамке с подписью модели

## Технологии

HTML5 · CSS3 (custom properties, grid, transitions, keyframes) · Vanilla JavaScript (ES6+): состояние корзины, рендеринг каталога, модальные окна · Google Fonts (Cormorant Garamond + Jost). Без сборщиков и зависимостей.

## Запуск

Открыть `index.html` в браузере — сборка не требуется.

```
├── index.html
├── css/style.css
├── js/main.js
├── img/          # 12 студийных фото товаров (3:4)
└── README.md
```
