# ГК Меридиан — корпоративный сайт с услугами и формой заявки

Корпоративный сайт вымышленной инжиниринговой группы «Меридиан» (проектирование и монтаж инженерных систем). Демонстрирует умение делать строгие B2B-сайты с плотной структурой, каталогом услуг и рабочей формой заявки.

## Что внутри

- **Топ-бар с контактами** и липкая шапка с навигацией
- **Герой-блок с анимированным чертёжным фоном** (blueprint-сетка + «плавающий» план на чистом CSS) и полосой ключевых цифр
- **Каталог услуг с раскрытием**: каждая из 6 карточек разворачивается и показывает состав работ
- **Портфолио проектов с фильтрами** по типам объектов (офисы, склады, промышленность, отели), 6 кейсов с метаданными
- **Форма заявки** с полной клиентской валидацией: имя, телефон с авто-маской `+7 ___ ___-__-__`, выбор услуги, **интерактивный слайдер бюджета** с живым отображением суммы, чекбокс согласия, экран успеха
- **Этапы работы** — 5 шагов с автонумерацией на CSS-счётчиках
- Мобильное полноэкранное меню, reveal-анимации, адаптив под все устройства

## Технологии

HTML5 · CSS3 (custom properties, grid, transitions) · Vanilla JavaScript (ES6+) · Google Fonts (Lexend + Inter). Без сборщиков и зависимостей.

## Роль разработчика (Екатерина Воронина)

- Дизайн-система: корпоративный синий + красный акцент, строгая типографика
