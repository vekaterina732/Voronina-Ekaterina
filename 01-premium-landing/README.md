# Люмен — премиальный лендинг SaaS

Одностраничный лендинг для вымышленной B2B-платформы продуктовой аналитики «Люмен». Проект демонстрирует умение строить конверсионную структуру лендинга и оживлять её аккуратным интерактивом без сторонних библиотек.

## Что внутри

- **Герой-блок** с асимметричной сеткой и нарисованным в коде мокапом дашборда (SVG-график, KPI-карточки, «инсайт дня»)
- **Параллакс мокапа за курсором** (только для устройств с мышью, `pointer: fine`)
- **SVG-график с анимацией отрисовки** (`getTotalLength` + dash-offset) и пульсирующей точкой на конце линии
- **Бегущая строка метрик** (data-ticker на чистом CSS, пауза при наведении)
- **Тарифная секция** с переключателем «помесячно / за год −20%» — цены пересчитываются анимированно
- **Интерактивные табы продукта**: воронка (бары растут при открытии), когорты, выручка
- **Анимированные счётчики** метрик (запускаются при попадании в зону видимости)
- **Слайдер отзывов** с точками, стрелками и автопрокруткой (пауза при наведении)
- **FAQ-аккордеон** на нативном `<details>`
- **Форма запроса демо** с клиентской валидацией email
- Плавное появление блоков при скролле (IntersectionObserver), sticky-шапка, мобильное меню

## Технологии

HTML5 · CSS3 (custom properties, grid, flexbox, keyframes) · Vanilla JavaScript (ES6+) · Google Fonts (Fraunces + Inter). Без сборщиков и зависимостей.

## Запуск

Открыть `index.html` в браузере — сборка не требуется. Для корректной загрузки шрифтов нужен интернет.

```
01-premium-landing/
├── index.html
├── css/style.css
├── js/main.js
└── README.md
```
