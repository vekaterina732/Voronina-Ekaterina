# Northwind Analytics — дашборд продуктовой аналитики (B2B SaaS)

Аналитический дашборд вымышленного SaaS-продукта «Northwind Analytics» — полностью на английском языке. Демонстрирует умение строить app-like SPA на чистом JavaScript: hash-роутинг, графики на SVG, таблицы с сортировкой и пагинацией, настройки с сохранением состояния.

## Что внутри

- **Hash-роутинг без перезагрузки** между разделами `#/overview`, `#/customers`, `#/orders`, `#/settings`; активный пункт подсвечивается в сайдбаре, неизвестный хеш редиректит на `#/overview`
- **App-layout**: тёмный сайдбар с навигацией и блоком пользователя, топбар с живым поиском и переключателем темы
- **Overview**: 4 KPI-карточки с анимированными счётчиками и дельтами (↑ зелёным / ↓ красным)
- **SVG-графики, нарисованные вручную из JS-данных**: линейный график revenue за 30 дней с hover-тултипом (точка + значение), столбчатая диаграмма signups по неделям, donut-chart трафика по источникам с легендой
- **Customers**: таблица 40 клиентов, генерируемая из JS-массива — сортировка по клику на заголовок (asc/desc со стрелкой), живой поиск (из топбара и из своего поля), фильтр-чипсы по статусу, пагинация по 8 строк
- **Orders**: таблица 24 заказов с фильтрами по статусу и итоговой строкой (сумма / количество), пересчитываемой при фильтрации
- **Settings**: рабочие переключатели — тёмная тема, компактная плотность таблиц, валюта USD/EUR (пересчёт всех сумм на лету); всё сохраняется в `localStorage` и применяется при загрузке
- **Полноценная тёмная тема** на CSS custom properties (класс на корневом элементе, persist в `localStorage`)
- **Тост-уведомления** при смене настроек; `Esc` закрывает тултип графика и мобильное меню
- **Демо-данные генерируются детерминированным псевдослучайным генератором** — выглядят органично, но стабильны между загрузками
- **Адаптив**: на <960px сайдбар уезжает за бургер с подложкой, таблицы скроллятся горизонтально, KPI — в 2 колонки, на <600px — в 1

## Технологии

HTML5 · CSS3 (custom properties, grid, flexbox, transitions) · Vanilla JavaScript (ES6+): hash-роутинг, рендеринг SVG-графиков, состояние таблиц, `Intl.NumberFormat`, `localStorage` · Google Fonts (Inter). Без библиотек, сборщиков и зависимостей.

## Запуск

Открыть `index.html` в браузере — сборка не требуется.

```
05-analytics-dashboard/
├── index.html
├── css/style.css
├── js/main.js    # роутер, графики, таблицы, настройки
├── js/data.js    # генерация демо-данных (детерминированная)
├── favicon.svg
└── README.md
```
